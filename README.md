# EduConvert

Конвертер старых РПД и ФОС в целевые шаблоны 2026 года.

Числа (зачётные единицы, часы, семестры, формы контроля) берутся из учебного плана `база.xlsx` — единственного источника истины. Текстовые блоки (компетенции, литература, тематический план, оценочные средства) переносятся из старых документов Word. Всё заполненное конвертацией выделяется жёлтым; старые числа идут только в отчёт о расхождениях.

## Возможности

- Пакетная обработка РПД/ФОС в форматах `.docx` и `.doc`.
- Числа из листа «План» (polars + fastexcel) — по ключевым словам шапки, с разбивкой по семестрам.
- §2 строится из листа «Компетенции», §4 — нумерованный список литературы, §8 — коды компетенций.
- Жёлтая подсветка изменённого; отчёт о расхождениях (Excel) и ZIP-архив с результатами.
- Изоляция сбоев и асинхронная обработка (блокирующие операции — в пуле потоков).
- Интерфейсы: CLI, веб (FastAPI + Flet), десктоп (Flet).

## Требования

- Python 3.14+
- Microsoft Word (Windows) — только для конвертации `.doc`.

## Установка

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python -m app.cli --db база.xlsx --input <папка-или-файлы> --out результат.zip   # CLI
uvicorn app.main:app --port 8000                                                 # веб
python -m app.ui.main_view                                                       # десктоп
```

Размеченные шаблоны — в `templates/` (пересборка: `python -m tools.build_templates`).
Демо без реальных данных: `python -m app.cli --db samples/план_пример.xlsx --input samples`.

## Тесты

```powershell
pytest        # или tox — с проверкой покрытия ключевых модулей ≥95%
```

## Структура

```
app/
├── main.py            # FastAPI + Flet
├── cli.py             # CLI
├── config.py          # настройки
├── core/              # бизнес-логика (не зависит от UI)
│   ├── models.py / interfaces.py / exceptions.py / normalizer.py
│   ├── excel_parser.py     # чтение «План»/«Компетенции»
│   ├── doc_converter.py    # .doc → .docx (MS Word COM)
│   ├── word_extractor.py   # чтение старых docx
│   ├── word_generator.py   # рендеринг docxtpl + подсветка
│   └── differ.py           # отчёт о расхождениях
├── services/orchestrator.py   # асинхронный ETL
└── ui/                # Flet (декларативный)
templates/             # размеченные шаблоны 2026
tools/build_templates.py
tests/
```

Данные между слоями передаются только Pydantic-моделями; `core/` отделён от UI Protocol-интерфейсами.
