# Синтетический пример данных

Здесь лежит **синтетический** демонстрационный набор (без реальных данных вуза),
на котором можно проверить работу EduConvert:

- `план_пример.xlsx` — мини учебный план с одной дисциплиной `Б1.О.01`;
- `Б1_О_01_РПД_Пример.docx` — исходная РПД. Старые числа в ней намеренно
  отличаются от плана (лекции 16 ≠ 12, практические 24 ≠ 10), чтобы
  продемонстрировать **отчёт о расхождениях** и «золотое правило» (в новый
  документ попадут числа из плана: 12 и 10).

## Быстрый прогон

```powershell
python -m app.cli --db "samples/план_пример.xlsx" --input samples --out пример.zip
```

В `пример.zip` будет сгенерированный `Б1.О.01_РПД_2026.docx` (часы из плана) и
`report.xlsx` со строками-расхождениями.

Файлы пересоздаются скриптом:

```powershell
python -m tools.make_sample
```
