# EduConvert

Конвертер старых РПД и ФОС в целевые шаблоны 2026 года, выверенный по одобренным эталонам кафедры.

Числа (зачётные единицы, часы, семестры, формы контроля) и атрибуты программы (направление, профиль, форма обучения — лист «Титул») берутся из учебного плана — единственного источника истины. Текстовые блоки (литература, тематический план, оценочные средства) переносятся из старых документов Word. Всё заполненное конвертацией выделяется жёлтым; старые числа идут только в отчёт о расхождениях.

## Возможности

- Пакетная обработка РПД/ФОС в форматах `.docx` и `.doc`; учебные планы — включая `.plx`-выгрузки (слитные коды семестров «12», лист «Титул»).
- Числа из листа «План» (polars + fastexcel) — по ключевым словам шапки, с разбивкой по семестрам; §2 — дословно из листа «Компетенции».
- РПД: официальная таблица тем заполняется темами исходника с масштабированием часов к Базе; §4 — нумерованный список литературы; §4.3 — интернет-ресурсы без дублей ЭБС; §8 — результаты лучшего уровня на все строки оценивания.
- ФОС: задачи с ответами → §1, тесты → §2 (формат «Задача № N: …»), шкалы оценивания не переносятся, раздел ГИА — только при наличии в исходнике.
- Эталонная вёрстка: титул с линиями до края строки, тело по ширине, числовые ячейки по центру, без пустых страниц.
- Исходники с заголовками без видимых номеров (автонумерация в стилях) распознаются по цепочке стилей; текст внутри гиперссылок и smartTag не теряется; объединённые ячейки сохраняются.
- Шаблоном можно выбрать саму официальную форму 2026 — конвертер разметит её на лету.
- Жёлтая подсветка изменённого; отчёт о расхождениях (Excel) и ZIP-архив с результатами.
- Изоляция сбоев и асинхронная обработка (блокирующие операции — в пуле потоков).
- Интерфейсы: CLI, веб (FastAPI + Flet), десктоп (Flet).

## Требования

- Python 3.14+
- Microsoft Word (Windows) — только для конвертации `.doc`.

## Установка

```powershell
py -3.14 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python -m app.cli --db база.xlsx --input <папка-или-файлы> --out результат.zip   # CLI
uvicorn app.main:app --port 8000                                                 # веб
python -m app.ui.main_view                                                       # десктоп
```

Размеченные шаблоны — в `app/templates/` (пересборка: `python -m tools.build_templates`);
вместо них можно указать чистую официальную форму 2026 — она будет размечена автоматически.
Демо без реальных данных: `python -m app.cli --db samples/план_пример.xlsx --input samples`.

## Тесты

```powershell
pytest        # быстрый прогон
tox           # тесты + лестница покрытия
tox -e lint   # ruff + mypy
```

Покрытие проверяется ступенями: ядро (`normalizer`, `word_extractor`) — ≥95%,
генерация и оркестрация — ≥88%, весь код без Flet-разметки — ≥88%. Сама разметка
порогом не защищена: тестами она по существу не покрывается — поэтому логика
экрана вынесена из неё в `app/ui/state.py`.

`mypy` проверяет ядро, сервисы и логику UI; область задана в `pyproject.toml`,
так что запускать его нужно без аргументов. Flet-разметка вне проверки: типы
Flet рассчитаны на его рантайм-диспетчер и в статике дают шум, а не дефекты.

## Структура

```
app/
├── main.py            # FastAPI + Flet
├── cli.py             # CLI
├── config.py          # настройки
├── core/              # бизнес-логика (не зависит от UI)
│   ├── models.py / interfaces.py / exceptions.py / normalizer.py
│   ├── excel_parser.py     # чтение «План»/«Компетенции»
│   ├── doc_converter.py    # .doc → .docx (MS Word COM)
│   ├── word_extractor.py   # чтение старых docx
│   ├── word_generator.py   # рендеринг docxtpl + подсветка
│   └── differ.py           # отчёт о расхождениях
├── services/orchestrator.py   # асинхронный ETL
├── ui/                # Flet (декларативный)
│   ├── state.py           # реактивное состояние экрана (логика, под тестами)
│   ├── main_view.py       # разметка главного экрана
│   └── components/        # переиспользуемые элементы
└── templates/         # размеченные шаблоны 2026
tools/build_templates.py
tests/
```

Данные между слоями передаются только Pydantic-моделями; `core/` отделён от UI Protocol-интерфейсами.

## Данные
